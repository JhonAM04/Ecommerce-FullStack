# 🛒 E-Commerce Full Stack Web Application

Este es un proyecto completo de una tienda en línea (e-commerce) desarrollado con tecnologías modernas tanto en el frontend como en el backend. El objetivo es ofrecer una experiencia fluida y segura de compra para los usuarios, así como una gestión eficiente del sistema para administradores.
Link: https://ecommerce-ten-gilt-40.vercel.app/
---

## 📌 Tecnologías Utilizadas

### 🧩 Frontend
- **React** ⚛️
- **TypeScript** 🟦
- **Tailwind CSS** 🎨

### 🔧 Backend
- **Python** 🐍
- **Django** 🦄

### 💾 Base de Datos
- **PostgreSQL** 🐘

### ☁️ Servicios
- **Supabase** (Autenticación, Almacenamiento, Base de datos como servicio)

---

## ⚙️ Funcionalidades

### Cliente
- Registro e inicio de sesión con validaciones
- Vista de productos con filtros y búsqueda
- Agregado y eliminación de productos al carrito
- Finalización de compra
- Generación de confirmación de pedido
- Modalidad de entrega configurable

### Administrador
- Panel de gestión de productos
- Gestión de pedidos
- Visualización de estadísticas básicas
